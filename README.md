# books

gemini的建议：
书名,                                        核心定位,特点
《A First Course in Probability》 (Ross),    数学基础,概率论的入门“圣经”。如果你概率基础薄弱，这本书是所有机器学习课的前置必修。
《AI: A Modern Approach》 (Russell & Norvig),百科全书,涵盖 AI 的全貌（搜索、逻辑、规划、博弈、NLP 等），机器学习只是其中一部分。
《PRML》 (Bishop),                           经典理论,深度聚焦于贝叶斯视角。推导极其优雅，是理解机器学习统计本质的必读书。
《MLAPP》 (Murphy),                          工具手册,现代且全面。涵盖了大量算法和应用，像一本查阅手册，广度超过 PRML 但推导略跳跃。


最精简的必读路径：
Ross《概率论》（打底） -> Bishop《PRML》（升华）
在读完 PRML 的前几章建立起统计直觉后，直接上手 Dive into Deep Learning (D2L) 或者 Goodfellow 的《Deep Learning》（花书）。


可以不读：
《AI: A Modern Approach》可以不读
《MLAPP》可以作为备选：如果你已经彻底啃透了 PRML，MLAPP 的大部分内容是重合的。只有当你需要查阅特定算法的概率模型时才需要它。
